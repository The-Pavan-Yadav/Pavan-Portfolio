## ✨ Key Features

### 🎨 Cyber & Deep Space Aesthetics
- **Dynamic Starfield Engine**: Custom canvas particle system generating twinkling stars and subtle spatial depth without degrading CPU/GPU performance.
- **Custom Interactive Cursor**: Smooth-lagged cursor pointer with hover scaling across interactive triggers, automatically disabled on touch devices.
- **Glassmorphic Surface Design**: Multi-layer dark interface (`#050505` canvas) with subtle borders (`#1F1F1F`) and soft blue/glow highlights.

### 🧭 Precision Floating Navigation
- Floating pill navigation bar with active section spy tracking (`#hero`, `#about`, `#skills`, `#projects`, `#certificates`, `#contact`).
- Smooth scrolling integration with scroll margins for seamless anchor jumping.
- Fully accessible mobile drawer menu with smooth backdrop blur and animated entrance transitions.

### 💻 Interactive "About Me" Terminal
- Built-in bash-style terminal emulator interface showcasing profile data, active interests, and development philosophies.
- Live typing headline with blinking prompt cursor.

### 🛠️ Categorized Skills Matrix
- Structured skill categories: **Languages**, **Frontend**, **Backend & Databases**, and **Tools & DevOps**.
- High-fidelity vector iconography using `react-icons` and `simple-icons`.

### 📂 Featured Projects Showcase
- Detailed project display featuring custom visual preview components, tech stack badges, and direct links to live deployments and GitHub repositories.
- Dedicated modal/archive view (`/projects`) for exploring complete development history.

### 📜 Verified Certificates & Authentic Badges
- **PDF Certificate Viewer**: In-browser document viewer powered by `pdfjs-dist` and `react-pdf` with modal previews and download links.
- **Real Credential Artworks**: Verified badge seals and official vector assets:
  - **IBM SkillsBuild**: AI Literacy Credential
  - **Fortinet**: NSE 1 Certified in Cybersecurity & Cloud Fundamentals
  - **Anthropic Claude Academy**: AI Fluency & Claude Code Credentials
  - **ISRO / IIRS**: AI/ML for Geodata Analytics & Atmospheric Sciences
  - **Stanford Online**: Machine Learning
  - **Google**: AI Essentials & Generative AI Learning Paths

### 📊 GitHub Activity Heatmap
- Live contribution calendar (`react-github-calendar`) displaying continuous open-source activity and commit consistency.

### ✉️ Functional Contact & Quick Connect
- Direct email contact system powered by **EmailJS** with real-time field validation and toast notifications via `react-hot-toast`.
- Quick-connect dock with instant shortcuts to GitHub, LinkedIn, Email, and Instagram.

## 🚀 Getting Started

Follow these instructions to run the portfolio locally on your machine.

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (version `18.0.0` or higher)
- [npm](https://www.npmjs.com/) (version `9.0.0` or higher) or [bun](https://bun.sh/) / [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/The-Pavan-Yadav/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Available Scripts

| Command | Action |
| :--- | :--- |
| `npm run dev` | Starts the Vite development server with HMR on port `3000` |
| `npm run build` | Compiles TypeScript and creates an optimized production bundle in `/dist` |
| `npm run preview` | Previews the production build locally |
| `npm run lint` | Runs `tsc --noEmit` to validate TypeScript types and catch syntax errors |
| `npm run clean` | Removes existing `/dist` build outputs |

## ⚡ Performance & Optimization Highlights

- **Tailwind CSS v4 Engine**: Zero-runtime, lightning-fast utility compilation.
- **Hardware-Accelerated Motion**: Transitions optimized via CSS transforms and opacity for constant 60 FPS animations.
- **Lazy Rendering**: Deferred loading for off-screen certificate previews and heavy canvas computations.
- **Zero Pill / Anti-AI Slop Aesthetic**: Meticulous micro-typography, precise letter-spacing, and balanced proportions across all display breakpoints.
- **Accessible & Responsive**: Fully responsive across mobile screens (320px+), tablets, and high-DPI desktop displays.
